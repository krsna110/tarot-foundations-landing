## ✨ Features
- **Mystical Celestial Aesthetics:** Deep midnight plum (`#150b24`), royal violet, and shimmering metallic gold foil gradients.
- **Ambient Twinkling Starfield:** 60fps dynamic canvas starfield with twinkling stars.
- **Interactive 3D Tarot Card:** Mouse tilt and click-to-flip hero tarot card with metallic reflections.
- **Interactive 4-Card Tarot Fan System:** Interactive spread connecting Cards, Planets, Astrology, and Timing.
- **Interactive Card Reveal:** Interactive tarot reading preview revealing insights, astrological associations, and timing.
- **Conversion-Optimized:** Sticky mobile CTA bar, clear curriculum breakdown, mentor credibility section, and FAQ accordions.
- **Ultra-Fast & Lightweight:** Pure Vanilla HTML5, CSS3, and JavaScript with zero heavy runtime dependencies.
